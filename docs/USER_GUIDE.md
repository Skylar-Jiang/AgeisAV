# AegisAV 用户手册

## 第一次启动

适用 Windows 11 x64、普通用户账户。将整个 ZIP 解压到本地目录（可含中文和空格），双击 `Start-AegisAV.cmd`。不需要 Python、Node.js、pip、管理员权限或修改 PATH；离线可用。启动会校验文件、检查至少 3 GiB 可用内存及 512 MiB 磁盘余量，绝不关闭其他项目。

浏览器打开 `http://127.0.0.1:3417/linen/`。第一次双击 `Access-Key.cmd`，在打开的记事本中复制密钥，粘贴到网页“本地访问密钥”，然后关闭记事本。密钥不放在地址栏或日志里，不要发给别人。有效会话保留八小时，同一个私有配置目录重启后可继续使用。

默认私有目录为 `%LOCALAPPDATA%\AegisAVDesktop`。包含访问密钥、任务及行为 SQLite、组件配置和服务日志，仅当前用户及 SYSTEM 可访问。软件目录中没有这些内容。换版本时保留私有目录；不要打包、提交、截图或公开它。

## 扫描文件与批量任务

在“工作台”选择良性 EXE、DLL、SYS，最多20份、单份16 MiB、整批32 MiB，点击“开始扫描”。只做静态分析，不运行文件。Windows 上不要上传真实恶意 PE；它们继续留在原隔离 Ubuntu VM 中。

任务页显示排队、运行、取消中、完成、部分失败、超时及重启中断。任务内相同字节可复用结果；它不代表不同任务被错误合并。取消会请求终止当前受监护扫描进程树；只有已完整返回的报告才保留。已取消/未完成的文件没有阴性结论。

文件详情保留五引擎的真实状态、版本、证据、耗时、模型分数与阈值。点击各引擎展开原始证据；可复制 SHA-256 和“导出 JSON”。缓存耗时来自原计算，文件墙钟单独记录。缓存、无命中、模型不适用、超时和缺组件分别展示。

**未定不等于安全。** 静态 `evidence-or-v1` 为证据 OR 基线，分数不是跨模型可比概率。参考库很小，不保证新家族覆盖，也没有正式独立 Recall/FPR。

## 任务、历史、资产和统计

“批量任务”支持活动/已结束筛选、分页与取消；“历史记录”能在服务重启后重新打开报告。“规则与模型”只读展示已安装版本、来源、适用范围与当前可用性，不在网页更改冻结阈值。“运行统计”取自本地任务数据库，不展示虚构准确率。

当前便携核心包含 SHA-256、TLSH/SSDeep、246条 YARA 规则及 YARA-X。**没有附送私有模型或 ClamAV 病毒库**；它们显示 unavailable / 弃权，不会自动当阴性。外部组件安装方法见“部署与故障排除”。

## 行为日志与进程链

打开“行为证据”，选择 UTF-8 Sysmon XML 或标准化 JSON，最多4 MiB、1,000事件。可先导入 `examples/sysmon_harmless.json`：这是6事件、2进程、1条规则信号的人工描述，所有命令从未执行。不要把它当真实恶意检测率证据。

页面展示来源、时间、缺字段、规则作者/版本/级别、进程链及事件原始字段。点击“查看证据”或“查看事件”筛选；每页25事件/50进程，可导出完整行为 JSON。命令行只显示为文本，不执行。

支持创建/终止、网络、文件、注册表及DNS等已声明事件。未支持事件保留并使状态不完整；采集缺失不代表没有发生。原生 EVTX 不支持，请先使用可信工具导出 UTF-8 XML；其他 EDR/JSONL 需显式转换，不能直接假装兼容。

规则目前只有两条固定 SigmaHQ 测试状态规则，使用明确受支持的字符串/布尔语义子集；regex、编码变换、聚合、跨事件 Sigma correlation 等会拒绝或标不支持。行为信号需复核，日志真实性、传感器完整性及实际执行均不保证。

## 将行为与静态报告关联

从某份静态详情点击“导入日志并尝试精确关联”。只有日志进程创建事件的 `Hashes` 中 SHA256 与该报告完全相同才关联，并标为**日志声明的哈希相同**。同名进程、PID重用和无关主机不会按名称强行关联。无精确证据时明确未关联。

即使关联成功，也没有独立验证日志真实性或证明该 PE 已被执行；当前报告不改静态阈值和判定。没有行为日志时显示 not_observed，不是行为安全。

## 停止、重启、备份和卸载

双击 `Stop-AegisAV.cmd` 正常停止；关闭网页不会停止后台。停止脚本只向此配置目录对应的已认证实例发请求，不按模糊进程名或不可信PID杀进程。

已完成报告重启后可查询；上传字节不保存。静态扫描中重启会标 interrupted、需重新提交；未完成行为导入需重新导入，不能伪造续扫。

备份前先正常停止，再复制私有目录（含两个SQLite、密钥和配置）到受控备份位置。不要在服务运行时只复制 SQLite 主文件而遗漏 WAL。恢复备份、删除私人报告和降级 schema 都应由用户确认后操作；启动器不自动删除它们。

卸载只需停止并删除自己解压的软件目录；没有系统安装项、计划任务、注册表、全局依赖或自动启动项。默认保留私有目录，避免误删报告。回滚先停当前版本，将旧的已校验ZIP解压到新目录，不覆盖正在运行的软件；数据库未来schema不兼容时会拒绝启动。

## 本地回放命令

```powershell
.\runtime\python.exe -I -B -m aegisav.behavior_cli .\examples\sysmon_harmless.json --output "$env:LOCALAPPDATA\AegisAVDesktop\exports\my-new-report.json"
```

输出必须在软件目录外且是新文件，不能覆盖旧报告。退出0表示生成报告，不代表安全；2为输入/输出拒绝、3为受限进程失败或超时。
