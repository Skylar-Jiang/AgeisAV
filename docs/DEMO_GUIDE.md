# 课程演示：可重复、安全、真实服务

预计8–12分钟。使用已解压包、正常用户与真实后端；下面的合成日志/坏输入只验证功能，不是恶意样本或准确率实验。演示过程不启动VM、不执行PE、不运行日志命令。

1. 展示ZIP SHA与Verify脚本通过，双击Start。首次通过Access-Key本地复制密钥登录；录屏前关闭记事本，不展示密钥、私有目录或敏感报告。
2. 工作台选本机 `C:\Windows\System32\notepad.exe`（只读取、不运行），再选一份纯文本作坏PE，展示实际提交、进度、部分失败；坏PE不是阴性。
3. 打开真实notepad详情，展开五引擎的版本、状态和证据。缺ML/ClamAV按实测显示unavailable；不要说五引擎全通过。展示未定/弃权不是安全，导出真实JSON。
4. 访问批量任务和历史，展示真实持久任务；进入规则/模型与运行统计，不展示虚构Recall/FPR。重复相同任务使用幂等键/网络重试不等同重新扫描不同语义任务。
5. 行为页导入 `examples/sysmon_harmless.json`，展示6事件、2进程、1规则信号。强调这只是无害人工描述，从未运行certutil或下载URL。展开规则作者/来源/版本和e1原始字段；显示父子链及网络/文件/注册表事件。
6. 从静态详情进入关联导入。若无精确SHA，展示“未关联”。要演示成功关联，可用文本编辑器复制此真实良性报告SHA，在合成日志的parent进程创建字段中增加 `Hashes: SHA256=<copied hash>`；仍标人工构造声明，不冒充真实执行或可信日志。导入后展示“日志声明的SHA相同”、相关节点和独立静态报告。
7. 导出行为JSON。Stop→Start，重新登录（若会话未过期可继续），从历史重新打开原静态/行为报告；说明扫描中重启需重新提交，没有虚假续扫。
8. 用测试脚本单独展示取消/超时/资源不足注入记录。把故障夹具与正常真实扫描区分，不让死循环、OOM或命令在演示主机上无界运行。
9. 收尾Stop，确认后台退出；软件目录可移动/卸载，私人报告仍保留。展示Engineering complete / Research open、两条Sigma/无原生EVTX/非动态沙箱等边界。

自动验收命令、实际截图、耗时和失败修复见本轮Stage G报告。自动脚本同样使用真实便携后端与浏览器，只有故障场景使用明确标注的受控注入。
