# 检测效果、数据角色与评测准入

整理日期：2026-11-22。下列数值来自 2026-10-22 的历史汇总，本次文档整理没有新增扫描或训练。
已有多引擎工程证据和开发实验；独立原始 PE 恶意10万+良性10万仍是未完成的研究目标，不能作为当前两章课程交付的硬门槛。
严格独立验证准入、最终集准入和独立人审均为0。未观察文件不能自动计入最终集。

机器结果见[汇总 JSON](benchmarks/course_evaluation_20261022.json)，
复现入口为[course_evaluation_summary.py](../experiments/course_evaluation_summary.py)。
脚本的完整重汇总需维护者的私有输入；公开仓库仅提供聚合 JSON 和 `--self-check`，缺少私有输入时不会伪造重建成功。
脚本仅打开明确列出的既有 JSON；不打开原始 PE、特征/预测数组，不访问网络或操作 VM。
结果中的输入摘要绑定历史来源；不公开样本 SHA、原始文件路径或私有标签包内容。

## R7去重与标签口径

原始成功主报告285行，成功R4补充报告13行；两者合并后298个不同SHA，重复0。
历史`paired-summary`已经包含补充13行，不能再把它与主/补充计数相加。
298个身份与观察账本完全一致，且与显式受保护的106个身份不相交。
本次逐引擎阳性和融合阳性均复现历史汇总。

标签分成286个`presumed_benign_operational`、10个`malicious_operational_proxy`和2个unknown。
10包括7个旧技术案例和3个新增自动高可信案例，仍然缺独立人审和严格准入。
两项技术/提供者家族争议为ZionSiphon/RustyStealer、DarkCloud/a310Logger，保持unknown。
unknown中的1个告警、1个未告警均保留；两者不进入下表的TP/FP/Recall/Precision分母。
因此“全部12个技术案例10次阳性”和“排除unknown后10个操作性案例9次阳性”同时成立。
不能把10个操作性案例改写为10个独立真值恶意文件。

`alert`明确表示报告`suspicious`或`malicious`。历史298份报告中15个`suspicious`、283个`undetermined`，
**没有一个`malicious`最终裁决**；ClamAV的4次匹配也产生`suspicious`证据。
`undetermined`在二值“是否告警”描述中为未告警，不能读作已判定安全。

## 当前标签和独立性准入

标签可信度与数据独立性分别记录。`analyst-case-admission-v1` 由
[label_admission.py](../experiments/label_admission.py) 校验记录完整性，不能认证填写者的断言。
MalwareBazaar 来源、厂商投票、有效签名或本系统预测都不能单独充当真值。

- `unknown`：精确身份/技术证据缺失、原始 SHA/PE 完整性失败或存在未解决争议。
- `probable`：主要技术报告将精确 SHA 关联到具体恶意目的，但原件验证或审阅未完成。
- `high-confidence`：精确技术证据、恶意目的、原始 SHA/严格 PE 核验和明确接受记录齐备。
  自动化审阅永远标为自动化，不冒充人审；恶意性与家族归属分开。
- 良性控制保留发布者渠道、包和成员摘要、签名及用途证据；签名/官方托管只构成代理依据，双用途/PUP 单列。

开发案例可以在明确代理标签与授权范围下自动探索。严格验证/最终准入还需真实标签接受与使用授权、
评分前冻结清单、未观察状态、精确/近重复/训练成员/来源/时间审计及残余风险接受。
R6 的自动机械核验不要求反复人工重做；来源组授权只能覆盖明确枚举的版本和成员，不能由一个示例推及未来版本。
R6 的人审字段未被填写；操作性实验授权不是严格验证签字。

可得 TLSH≤40 / SSDeep≥80 图须覆盖新旧身份和旧身份之间的桥接，连通组一并留出。
同时保留家族/活动、项目/发布/包/共享组件分组；未知家族不能自动算独立单例。
相似边只是保守筛查，不能证明统计独立。完整上游训练成员不可得时如实披露，不能写成 overlap cleared。
COFF 时间、签名时间、发布时间、获取时间和 first_seen 分开，不能由 PE 头推断全球首次出现。

最终集只对冻结后的方案做一次检验，不按验证反馈挑最终样本；既有观察不能被标签修订抹除。
比较同时报告全输入/成功分母、恶意弃权计漏检的保守 Recall、引擎贡献、错误、按来源/家族/架构/类别分层和实际成本。
样本量不足时保留描述性结果。零误报的单侧 95% IID 上界为 `1 - 0.05**(1/n)`；
FPR≤0.1% 至少需要 2,995 个独立抽样及总体代表性依据，成百个相关 SDK DLL 不满足该条件。
适用时同时提供来源/组件分组重抽样，不能以 IID 区间掩盖来源相关性。
