## 失败与审查修正

首版测试将上传背压 429 错当作幂等失败；改为尊重 Retry-After 并沿用同键重试，
没有放宽并发额度。构建首次遇遥测配置跨盘 EXDEV，设置 NEXT_TELEMETRY_DISABLED=1 后通过。
审查确认 Windows communicate 在读取前可能阻塞输入：新增 1 MiB 不读取夹具，
0.5 秒截止红测曾耗 2.219 秒；改为独立输入线程与主线程截止监控后通过。
同时修正整批历史反序列化、Linux 依赖解析器信号处理、任务终态早于剩余文件状态、
临时文件分配失败的 Job 句柄清理。保留问题说明，不以早期通过探针掩盖边界错误。
