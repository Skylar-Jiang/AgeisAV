# Stage G：Windows 11 便携软件交付（2026-10-19）

## 交付结论与使用

AegisAV 0.2.0 使用便携ZIP，不制作庞大单EXE，不要求最终用户安装Python或Node。软件层完成真实候选包验收；发布包的确切SHA、体积和最终复核记录保存在包外 `build-summary.json`、`.sha256` 及交付验收记录，避免把ZIP自己的摘要循环写进ZIP。此报告不是科学准确率验收。

解压整个目录，普通用户双击 `Start-AegisAV.cmd`，浏览器打开本机回环工作台。首次通过 `Access-Key.cmd` 在本机记事本复制新建的私有访问密钥登录。结束用 `Stop-AegisAV.cmd`，关闭网页不会停止后台。无需申请MalwareBazaar凭据，不读取Windows DPAPI。使用手册、部署/故障排除、课程演示和已知限制同时提供MD与离线HTML。

## 失败修复与资源

首轮真实便携验收发现外置ML继承无效宿主PYTHONHOME，报告正确error而非阴性；独立复现同一ML Python在污染/净环境分别退出1/0。桌面服务移除宿主PYTHON配置，仅传入自己审核的路径后，实际包内五引擎报告中ML变为no_match。不改模型、特征、Worker、规则、阈值、融合或SQLite schema。

审查/回归修复：旧Stop会将401或监听关闭过早当退出；现以认证身份加贯穿完整服务生命周期的租约确认。启动超时登记pending并回收仅本次Popen，租约与身份栅栏阻止重试覆盖旧进程身份。原ACL grant追加会保留Everyone，现用Windows DACL替换，包括已有受控文件。实际测试中在自己临时密钥文件制造错误后finally恢复，不读取既有凭据。

候选包单次功能测量：解压5.55秒、启动11.52秒、正常停止2.88秒、重启9.85秒；notepad核心文件墙钟4.60秒，外置ML4.03秒。不同运行时/缓存/并行测试影响明显，**不是公平性能对比或加速声明**，无P50/P95/吞吐量推断。最终单次与服务内存另存交付记录。既有F的受限行为容量实验保留，不用夹具冒充检测性能。

原进程树限制、串行扫描、3GiB桌面启动余量/512MiB磁盘门槛、256MiB行为子进程不变；VM仍是既定8GiB宿主启动门槛，未降低。测试结束只关自有服务/浏览器并清理自己可再生成的临时目录，正式数据/模型/快照保留。
